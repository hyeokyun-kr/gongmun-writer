공문 작성기 사용 안내

  1. 받은 공문과 요청사항 목록을 올리세요.

    공문(PDF)에서 기관·참조·제목·문서번호·일자를, 요청사항 목록(한글·PDF·Word)에서 요청사항을 찾아 채웁니다. 찾지 못한 값은 직접 입력하세요. 파일은 외부로 전송되지 않습니다.

  2. 표지 정보와 요청사항을 확인하세요.

    요청사항은 항목별로 고치거나, 순서·단계(1. / 가.)를 바꾸거나, 추가·삭제할 수 있습니다. 원문 번호가 Word 자동 번호와 다르면 ‘[요청사항 N]’을 붙입니다.

  3. 미리보기에서 내용을 검토하고 수정하세요.

    본문을 클릭하거나 ‘본문 직접 수정’을 누르면 문장을 수정할 수 있습니다. 직접 수정 후에는 기본 정보가 바뀌어도 해당 문장이 자동으로 덮어써지지 않습니다.

  4. ‘Word로 저장’을 누르세요.

    원본 DOCX의 레터헤드·글꼴·머리말·페이지 번호를 포함한 Word 문서를 저장합니다. 파일을 Word에서 열어 최종 배치를 확인하세요.

  5. 심사보고서 의견서도 같은 방법입니다.

    공정위 ‘심사보고서 송부 및 의견제출 요청’ 공문을 ①에 올리면 ‘심사보고서 의견서’로 바뀌어 의견서 제출 공문, 겉표지, 목차, 본문 뼈대(I. 요지 ~ 결론), 첨부서류(소을호증)를 만듭니다. ②에 심사보고서 PDF를 올리면 우리 법인이 대리하는 회사의 정식 이름과 담당변호사를 찾아 줍니다.

  6. 제출기한 연장신청은 맨 위에서 먼저 고르세요.

    ‘제출기한 연장신청’을 누른 뒤 받은 공문(자료제출 요구 또는 심사보고서 의견제출 요청)을 ①에 올리면, 원 요청(2번 문단)과 기본 연장 사유(3번 문단)를 채웁니다. 연장 기간(1~4주)을 누르면 연장 기한과 요일이 들어갑니다(4번 문단). 같은 공문으로 회신도 만들 수 있어서 프로그램이 스스로 고르지 않습니다.

  7. 다시 사용할 사건은 ‘사건 저장’을 누르세요.

    입력과 수정 내용, 첨부 목록, 변호사의 현재 연락처를 JSON 파일로 저장합니다. 변호사 명단을 바꿨다면 명단도 별도로 저장하세요.

설치·로그인·인터넷 연결이 필요하지 않습니다. 브라우저에 사건정보를 자동 보관하지 않습니다. 창을 닫기 전에 필요한 사건을 파일로 저장하세요. 인쇄/PDF는 화면 미리보기를 사용하므로, 최종 제출용 PDF는 저장한 DOCX를 Word에서 변환하는 것을 권합니다.
