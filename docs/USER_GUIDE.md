# 공문 작성기 1.0 사용 안내

> 이 문서의 로펌 이름(법무법인 예시), 변호사 명단, 회사·사건 이름은 모두 가짜 예시입니다. 실제로 쓸 때는 `firm/`의 설정과 양식을 바꿉니다(README 참고).

`dist/gongmun-writer.html`을 Chrome 또는 Edge에서 열면 바로 쓸 수 있습니다. 설치, 로그인, 서버, 인터넷 연결이 필요 없습니다. 다른 PC에는 이 HTML 파일 하나만 복사하면 됩니다. 올린 파일은 브라우저 안에서만 읽고 외부로 전송하지 않습니다.

## 화면 구성

- **왼쪽 맨 위 ‘만들 문서’ 탭**에서 [자료제출 회신] [심사보고서 의견서] [제출기한 연장신청] 중 하나를 먼저 고릅니다. 처음에는 ‘자료제출 회신’입니다. 고른 문서에 맞게 올리기 칸과 입력 칸이 바뀝니다. 같은 공문으로 회신도 연장신청도 만들 수 있어서, 연장신청은 프로그램이 스스로 고르지 않습니다. 회신 ↔ 의견서는 예전처럼 올린 공문의 종류를 보고 자동으로 바뀝니다. ‘추가 설명자료’, ‘직접 작성’은 회신 탭의 1번 칸에서 고릅니다.
- 넓은 화면(가로 1360픽셀 이상): **왼쪽**은 파일 올리기와 1~3번 칸(공문과 기본 정보, 수신과 제출 주체, 원 요청과 본문), **가운데**는 미리보기, **오른쪽**은 4~7번 칸(첨부 자료, 본문, 첨부서류, 담당변호사)과 맨 아래 ‘Word로 저장’입니다.
- 노트북처럼 좁은 화면에서는 1~7번 칸이 왼쪽에 한 줄로 이어지고 미리보기는 오른쪽에 있습니다. 위의 ‘새 공문·사건 저장’ 줄과 아래의 ‘Word로 저장’ 줄은 스크롤해도 늘 보입니다.

## 업무 흐름

1. **받은 공문과 요청사항 목록을 올립니다.** 왼쪽 위 초록 테두리의 ‘공문과 요청사항 목록 올리기’에서 각 칸의 **파일 선택**을 누르거나 파일을 칸 위로 끌어다 놓습니다. 파일을 끌고 화면에 들어오면 두 칸이 깜빡여 놓을 곳을 알려 주고, 다 읽으면 칸에 체크 표시와 파일 이름이 나옵니다.
   - ① 받은 공문: PDF(한글·Word도 가능). 수신 기관, 참조 부서, 공문 제목, 문서번호, 시행일, 수신 회사를 찾아 **표지**를 채웁니다.
   - ② 요청사항 목록: 한글(HWP·HWPX), PDF, Word(DOCX), 텍스트. 요청사항에 **번호를 매겨 첨부 본문**을 만듭니다.
   - 칸을 바꿔 넣어도 공문 형식(수신·제목·시행)을 보고 알맞은 칸으로 읽습니다.
   - **다른 사건의 파일을 올리면** 새 사건으로 봅니다. 예를 들어 의견서를 만들다가 자료제출 공문을 올리면, 다른 칸에 남아 있던 앞 사건 파일(심사보고서)은 비우고 화면 아래에 알려 줍니다. 앞 파일에서 자동으로 채운 값(첨부 줄, 사건번호, 비공개 문구 등)도 새 파일 기준으로 다시 채웁니다. 직접 입력하거나 고친 값(제목, 본문 뼈대 등)이 있으면 바꾸기 전에 묻습니다. 고른 담당변호사는 그대로 둡니다. 처음부터 새로 하려면 ‘새 공문’을 누르세요.
   - ②칸 파일을 먼저 바꾼 뒤 ①에 다른 공문을 올리면, ②칸 파일을 새 공문과 함께 쓸지 묻습니다.
   - 공문과 요청사항 목록(또는 심사보고서)을 한꺼번에 끌어다 놓아도 공문은 ①, 나머지는 ②로 읽습니다. 한 번에 두 파일까지 놓을 수 있습니다.
2. **채워진 값을 확인합니다.** 올리기 칸 아래 ‘문서에서 찾아 채운 값’에 찾은 값과 못 찾은 값이 표시됩니다. 미리보기에서 표지와 첨부 본문을 확인하고, 입력 칸이나 미리보기를 눌러 고칩니다.
3. **담당변호사(7번 칸)를 고르고 ‘Word로 저장’을 누릅니다.** 표지와 첨부 본문(요청사항 양식)이 한 Word 파일로 저장됩니다. 고객 자료를 받아 Word에서 각 요청사항 아래 빈 줄에 답변을 씁니다(4단계).

## 자동으로 채우는 값과 확인할 점

| 항목 | 채우는 방법 | 확인할 점 |
| --- | --- | --- |
| 발신일자 | 공문의 제출기한(공문에 없으면 요청사항 목록에서) | Word에서 노란색으로 표시. 실제로 보내는 날이 다르면 고치기 |
| 관리번호 | ‘26-*’ (앞 두 자리는 발신일자의 연도) | ‘*’는 Word에서 노란색. 번호를 알면 ‘26-1234’처럼 입력 |
| 수신 기관·기관 호칭 | 공문 맨 위 기관명(‘수신’ 바로 위 줄) | 위원회 → ‘귀 위원회’, ○○청 → ‘귀 청’ |
| 참조 | 공문·요청서의 ‘○○국 ○○과’ 또는 문서번호의 과 이름 + ‘장’ | ‘참조 다른 표기’ 버튼으로 ‘(담당자: ○○○ 조사관님)’ 형식 선택 가능 |
| 제목 | 공문 제목에서 요청 명칭을 뽑아 ‘…에 대한 회신’ | ‘요청 명칭’ 아래 버튼(자료제출 요청·요구 등)으로 바꾸면 제목·첨부명도 함께 바뀜 |
| 요구일자 | 공문의 시행일(결재일) | 접수일을 쓰는 경우 직접 고치기 |
| 문서번호 | 공문 하단 ‘시행’ 번호 | 예: (사건처리)○○과-0000 |
| 제출 주체 | 공문 ‘수신’의 회사명, ‘(주)’ → ‘주식회사’ | ‘약칭’을 넣으면 ‘(이하 “약칭”)’ 형식으로 씀 |
| 인용 형식 | 공정거래위원회는 대괄호식 [문서번호: …], 그 밖의 기관은 낫표식 「공문 제목」 | 필요하면 바꾸기 |
| 첨부 | ‘회신 제목 1부’ | 첨부명은 첨부 본문 제목으로도 쓰임 |

- 제출기한은 발신일자로 넣고, 시각까지 적힌 원문(예: 2026. 1. 9. 18시)은 ‘참고’에 보여 줍니다. 사건번호, 담당자는 참고로만 보여 줍니다(문서에는 넣지 않음).
- 공문 수신란에 ‘가나다’처럼 상호만 있으면 그대로 넣고, 정식 상호(예: 주식회사 가나다)를 확인하라고 안내합니다.
- ‘일부 회신’을 켜면 ‘일부 회신하오니’로 씁니다. 2번 문단은 미리보기를 눌러 자유롭게 고칠 수 있습니다.

## 요청사항(첨부 본문)

- 요청사항 목록의 ‘자료제출 요청사항’, ‘소명요구 내용’ 같은 제목 뒤부터 ‘유의사항’ 앞까지에서 번호 항목(1. / 가. / (1) / 2-1. 등)을 찾습니다. 한글의 자동 문단 번호도 인식합니다.
- Word에는 ‘1.’·‘가.’ **자동 번호 제목**으로 저장됩니다. Word에서 항목을 넣거나 지우면 번호가 다시 매겨집니다.
- **원문 번호 표시**: ‘자동’이면 요청서 번호가 Word 번호와 다를 때만 ‘[요청사항 2-1]’처럼 원문 번호를 붙입니다(회신 샘플 방식). ‘표시’·‘표시하지 않음’으로 바꿀 수 있습니다.
- ‘2. 귀사의 ○○ 관련,’처럼 하위 항목(2-1, 2-2)의 머리말인 항목은 하위 항목 앞에 합칩니다.
- `*`, `※`, `-`, `ex)` 같은 **세부 내용**은 해당 요청사항 아래 작은 글씨로 넣습니다. 끌 수 있습니다.
- 요청서 안의 **표(작성 양식)는 옮기지 않습니다.** 옮기지 않은 표가 있으면 안내합니다.
- 각 항목은 5번 ‘요청사항 · 첨부 본문’ 칸에서 고치기, 원문 번호 고치기, ‘하위로/상위로’(1. ↔ 가.), 순서 바꾸기, 삭제, 추가가 됩니다. 미리보기의 요청사항을 누르면 해당 칸으로 이동합니다.
- 미리보기의 점선 상자 ‘답변 작성란’은 화면에만 보입니다. Word에는 빈 줄로 들어갑니다. 아래에 가.·나. 항목이 있는 상위 제목에는 답변란 없이 한 줄만 띄웁니다.
- 파일을 읽을 수 없으면 ‘요청사항을 붙여넣어 입력하기’에 요청사항 부분을 붙여넣으세요.
- 본문 끝 ‘첨 부 서 류’(1. 참고자료 23 ⇥ 자료명)는 ‘첨부서류(참고자료) 목록’ 칸에 넣었을 때만 들어갑니다.

## 심사보고서 의견서 (2026-10-21 추가)

공정위 ‘심사보고서 송부 및 의견제출 요청’ 공문으로 **의견서 제출 공문과 의견서 양식**을 만듭니다. 형식은 2026년 의견서 샘플을 따릅니다.

1. 공문(PDF)을 ①에 올립니다. 자동으로 ‘심사보고서 의견서’ 유형으로 바뀝니다(맨 위 ‘만들 문서’ 탭에서 직접 고를 수도 있습니다).
2. (선택) 심사보고서(PDF)를 ②에 올립니다. 피심인 목록에서 **우리 법인이 대리하는 회사**(`firm.json`의 `match`)를 찾아 정식 이름을 채웁니다. 요약 상자에 ‘심사보고서의 우리 법인 변호사 ○○ 추가’ 버튼이 나옵니다.
3. 미리보기에서 확인하고 담당변호사를 고른 뒤 Word로 저장합니다.

| 항목 | 채우는 방법 |
| --- | --- |
| 발신일자 | 공문의 제출기한(노란색) |
| 참조 | 공문의 제출처: ‘심판총괄담당관실, 국제카르텔조사과’ → ‘심판총괄담당관, 국제카르텔조사과장’ |
| 제목 | ‘심사보고서에 대한 의견서 제출’, 감면 건은 ‘[감면] …’ |
| 2번 문단 | 귀 위원회의 「사건명」(사건번호)과 관련하여, 피심인(신청인) ○○는 첨부와 같이 심사보고서에 대한 의견서를 제출합니다. |
| 첨부 | 공문의 제출부수: ‘첨부: 심사보고서에 대한 의견서 15부(심판총괄담당관실 10부, ○○과 5부). 끝.’ |
| 서명 | ‘주식회사 ○○ 대리인’ |
| 사건명 | 공문의 사건명. ‘(주)’는 ‘㈜’로 바꾸고, 감면 공문에 가려진 이름(*****)은 회사 이름으로, 감면 건은 끝에 ‘(비공개)’ |

- Word 파일은 **공문 표지 → 겉표지(사건명·사건번호·피심인, 쪽번호 없음) → 목차(i, ii) → 본문 → 첨부서류(소을호증)** 순서입니다. 본문 뼈대는 ‘I. 심사보고서 및 피심인 의견 요지(1. 심사보고서 요지, 2. ○○ 의견 요지) / II. [의견 제목] / III. 결론’입니다. 5번 칸에서 제목을 고치거나 더할 수 있습니다.
- 목차는 Word 자동 목차입니다. 의견을 다 쓴 뒤 목차에서 마우스 오른쪽 → ‘필드 업데이트’ → ‘목차 전체 업데이트’를 고르면 바뀐 제목과 쪽 번호가 함께 맞춰집니다(‘쪽 번호만 업데이트’는 제목 변경을 반영하지 않음).
- 감면 건은 샘플 의견서의 **비공개 요청 문구**(형사소송 관련)를 본문 앞 상자에 넣어 둡니다. 사건에 맞지 않으면 3번 칸에서 고치거나 지우세요.
- 공문에 이름이 가려져 있고 심사보고서도 없으면 ‘제출 주체’를 직접 입력해야 저장됩니다.
- ‘공문 뒤에 의견서 양식을 함께 저장’을 끄면 공문만 저장합니다.

## 제출기한 연장신청 (2026-10-28 추가)

공정위·중기부 등의 자료·의견 제출 기한을 지키기 어려울 때 내는 **연장신청 공문**을 만듭니다. 공문만 만들고 본문은 없습니다. 문장은 연장신청 샘플(자료제출 요구용, 심사보고서 의견서용)을 따릅니다.

1. 맨 위에서 **‘제출기한 연장신청’**을 누릅니다.
2. 기한을 연장하려는 **받은 공문**(자료제출 요구 또는 심사보고서 의견제출 요청)을 ①에 올립니다. ②칸은 없습니다.
3. 3번 칸에서 **연장 기간(1주~4주)**을 누르면 연장 기한과 요일이 들어갑니다. 10일처럼 주 단위가 아니면 ‘연장 기한’에서 날짜를 직접 고릅니다.
4. 연장 사유를 확인·수정하고, 담당변호사(5번 칸)를 고른 뒤 Word로 저장합니다.

| 문단 | 자동으로 쓰는 문장 | 입력 칸 |
| --- | --- | --- |
| 2. 원 요청 | 자료제출: 귀 청의 2026. 1. 5.자 「공문 제목」(문서번호: …)와 관련하여, 귀 청은 ○○ 주식회사에게 2026. 1. 9.(금)까지 자료제출을 요청하였습니다. / 의견서: 「사건명」(사건번호: …)과 관련하여, 귀 위원회는 ○○(이하 “피심인”)에게 심사보고서를 송부하면서 ….까지 심사보고서에 대한 의견서를 제출할 것을 요구하였습니다[문서번호: …]. | 공문에서 자동. 두 번째 연장이면 ‘이미 한 번 연장받음’을 켜고 연장 회신 문서번호와 연장받은 기한을 넣으면 ‘…회신(문서번호: …)을 통해 ….까지 제출기한을 한 차례 연장해 주신 바 있습니다.’가 붙습니다 |
| 3. 사유 | 현재 ○○는 최선을 다하여 신속하게 제출 자료를(의견서를) 준비 중에 있으나, 구체적인 사실관계를 확인하고 관련 자료를 정리하는 데 추가적인 시간이 필요한 상황입니다. | ‘연장 사유’ 칸에서 고침. 줄을 바꾸면 번호 문단이 나뉨. ‘기본 사유 문장으로 돌아가기’ |

## Word 파일 구성

- 1구역 **표지**: 기존과 같은 레터헤드·서식·담당변호사 연락처. 확인할 곳인 발신일자와 관리번호의 ‘*’는 노란색 형광펜으로 표시됩니다. 보내기 전에 확인하고 지우세요.
- 2구역 **첨부 본문**: `<첨부>`, 본문 제목(가운데·굵게·밑줄), 요청사항 제목(자동 번호·양쪽맞춤), 세부 내용(10pt), 답변용 빈 줄, (선택) 첨부서류 목록. 첨부서류 목록은 페이지 나누기 뒤 새 쪽에서 시작합니다. 두 번째 쪽부터의 로펌 머리말을 쓰고 쪽번호는 1부터 다시 셉니다.
- 요청사항이 없거나 ‘첨부 본문 함께 저장’을 끄면 v2처럼 표지만 저장합니다.

## 그대로 유지한 v2 기능

- 공문 유형(자료제출 회신·추가 설명자료·직접 작성), 본문 직접 수정, 첨부 목록, 사건 저장/불러오기(JSON), 변호사 명단 관리(예시 명단 52명, `firm/firm.json`), 인쇄/PDF, 텍스트 복사.
- **기존 Word 변호사 추가·편집**: 이제 표지 뒤에 첨부 본문이 있는 회신 문서(이 프로그램 결과물, 변호사가 고친 최종본)도 받습니다. 첨부 본문은 그대로 두고 표지의 담당변호사만 바꿉니다.
- 예전(v2)에 저장한 사건 파일도 불러올 수 있고, 그때의 문장을 그대로 씁니다.

## 한계

- 스캔(이미지) PDF는 글자를 읽을 수 없습니다. 값을 직접 넣거나 ‘공문 텍스트를 붙여넣어 날짜·문서번호 후보 찾기’를 쓰세요.
- 암호·배포용(복사 방지) 한글 문서는 읽을 수 없습니다. 한글에서 PDF로 저장해 올리세요.
- PDF에서 줄이 바뀐 곳의 띄어쓰기는 추정합니다. 한글 공문은 낱말 중간에서도 줄이 바뀌므로, 예컨대 ‘신규 거래’ 끝에서 줄이 바뀌면 ‘거래중단’처럼 붙을 수 있습니다. 요청사항 문장을 한 번 읽어 보세요. 한글·Word 파일에서 읽은 요청사항에는 이 문제가 없습니다.
- 자동 값은 문서에 적힌 그대로입니다. 원문의 오타(예: 회사·부서 이름의 글자 하나가 틀린 경우)나 번호 오류(같은 ‘다.’ 두 번)는 고치지 않습니다.
- 화면 미리보기와 Word의 줄바꿈·쪽 나눔은 다를 수 있습니다. 최종 배치는 Word에서 확인하세요.
